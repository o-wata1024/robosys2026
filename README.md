# ToDo Manager
 TODO Managerは、ターミナル上でタスクを登録・管理するためのコマンドライン型TODO管理プログラムです。
 
 タスクの追加、一覧表示、完了、削除などを簡単に行うことができます。
 登録したタスクはJSONファイルに保存されるため、プログラムを終了してもデータが保持されます。
